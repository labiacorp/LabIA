# Domain docs

## Layout

This repository uses a single context:

- GLOSSARY.md at the repository root.
- Architecture decision records under docs/adr/.

## Reading rules

Before exploring an area, read the glossary and relevant decision records
when they exist. If they are absent, continue silently.

Create entries when real terminology or architectural decisions are
resolved during authorized work.

Use the glossary's terminology consistently. Surface conflicts with existing
decision records before proposing a different direction.

The code remains the source of truth; PROJECT_STATUS.md records current
implementation state.
