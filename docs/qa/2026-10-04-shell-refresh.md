# Shared shell and dashboard refresh

Header actions and page navigation are separated. A native creation dialog offers the three existing free entry routes. Shared theme tokens support light/dark appearance; a pre-paint initialization script and localStorage retain the browser preference without changing account or provider settings. Narrow screens expose balance through the account menu.

Browser verification: desktop and 390px, both themes, persistence after reload, creation dialog and navigation/account controls. No production data was changed and no generation was submitted. Existing generation and ownership behavior is unchanged. Typecheck, lint, full test suite and production build are checked before push.
