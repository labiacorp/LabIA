# Competitor study (2026-10-06)

What each product does, what LabIA should take, and what to skip. Explored logged in as a founder; one persona created on Creathoon (15 Berrys of free credit) to see the full flow.

## Creathoon (creathoon.com/app)

Currency "Berrys" (free tier 25), plus points, streak and "Improves" (prompt-rewrite credits). Top nav (Create, Explore, Academy, Earn, My, Buy) and a left sidebar on Home; several tools use their own shell, so the product feels stitched together.

| Area | What it is | Take for LabIA? |
|---|---|---|
| Home | Hero with two CTAs (Open Canvas, Create Avatar), stat row (credits, points, plan, streak), tool grid with filter chips and search, "coming soon" cards | Tool grid with real thumbnails, yes. Points/streak no. |
| AI Avatar, onboarding | 3-screen "how it works" carousel with a real persona case (reference → identity → new scenes), "nothing is charged now" | Yes: our studio has no explainer. |
| AI Avatar, creation | Left stepper Identity → Vibe → Birth. Identity: start (distinctive / custom / use a photo), appearance tabs Hair/Body/Identity as image cards, name + optional reference photo with rights checkbox. Vibe: personality and image-tone chips, typical scenes, voice (ElevenLabs voices or native audio). Birth: summary, **per-item cost list (sheet 2K 4, front 4, 45° 4, full body 3) and "balance 25 → 10"**, Confirm with the price on the button | **Yes**: cost list with balance before → after on the confirm screen; "only the name is required"; rights checkbox for a reference photo. |
| AI Avatar, run | Live panel: % ring, elapsed vs usual time, each node with status and cost, "you can leave, it keeps generating", Cancel, "Notify me when done". Then "Your avatar is ready": 3 identity views, next steps (first photo, scene + video) | **Yes**: our kit generation has no live progress panel. |
| Persona studio | Workspace per persona: chip "face locked · 3 views", left nav (Create, Shoot, Copilot, Gallery, Reel, UGC campaigns, Carousel, Wardrobe, Motion Swap), assets strip, composer at the bottom (Photo scene / Scene + video / Animate; format, quality, model chips; Generate with cost), right panel **Today (spend), Runs (node graph of each run with time and cost), Identity, Public media kit** | **Yes, this is the shape of our influencer page.** The Runs node graph is the canvas we lost. |
| Shoot | "Describe the photoshoot" + 2–6 photos; planning is free, price shown on the next screen | Yes, later: a pack of scenes in one go. |
| Copilot | Chat per persona with chips: scenes for today, write a caption, plan the week, script (hook → value → CTA), 10 opening hooks; suggestions become one click into the composer | Yes: chips are a cheap way to make the script step richer. |
| Gallery (persona) | Type filters (photos, videos, canonical views, sheets), favorites, multi-select → Motion video / Build Reel | Yes: multi-select to build a reel. |
| Carousel | Slides strip, AI script per post (2 Berrys), export (1 Berry) | Later. |
| UGC campaigns | Brief form → matrix 1 avatar × 5 hooks × 1 demo × CTA; planning free, generation quoted separately | Later (brands). |
| Wardrobe | Outfits, locations, props reusable across personas (unstyled, unfinished) | Idea worth keeping: consistent outfits. |
| Canvas (/canvas) | Single-image editor: upload or AI Magic (model, up to 4 extra images, aspect, prompt with templates/improve/history), tools (text, ads creator, upscale, BG remove, more "soon"), Remix/Download/share to X | No: weak. Our canvas should be the run/production graph. |
| Motion Swap | Upload a 3–15s video + character, model "Mimic", community feed with "Recreate" | We have it (/trends). Take the community "Recreate" feed later. |
| Motion Studio | Brand video from website/logo/photos, script examples, 4 formats, takes you can reopen for free | Skip (brands, different niche). |
| Prism | Paste a website URL → brand kit | Skip. |
| Planning | Calendar; does not post ("copy the caption, download, post yourself") | We will post for real (Felipe's integrations): our edge. |
| My creations / Gallery | Creations kept 24h unless saved to the gallery | Skip the 24h rule. |
| Explore | Community feed filtered by model | Later, needs volume. |
| Academy | Short tutorials/articles, PT-BR SEO titles | Later, for SEO. |
| X Radar | Grok search on X with raw filters (dates, accounts, temperature) | Skip. |
| AI Agent | Chat agents by job (social, marketing, launch, support) | Skip; Copilot per persona is better. |
| Earn | Daily check-in streak (+10 to +35), daily/weekly missions, top-10 leaderboard | Skip for now (gimmicky). |
| Refer & Earn | Link + copy/share, stats (invitations, conversions, earned, pending), rules: friend +2, you +3 on sign-up, +25 on first purchase, list of referrals | Yes: our /conta#indicacoes should show these four stats and the list. |
| My account | Profile card, stats, balance summary, **ledger with type/period filters and CSV export**, redeem a code | Ledger filters + export, yes. Redeem code fits our access code. |

**Lessons:** show the price per item and the balance after, before confirming; keep the user informed while it runs; one workspace per influencer with the composer, assets and run history together. Avoid their mistake: many tools, many shells, half-finished pages ("soon" everywhere).
